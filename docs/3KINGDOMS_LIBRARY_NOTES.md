# Заметки по библиотеке «Троецарствия»

Источник: [официальная библиотека игры](https://3kingdoms.ru/info/library/)  
Проверено: 17 июля 2026 года.  
Назначение: быстрый справочник для анализа экранов, игровых сущностей и сценариев в этом репозитории.

## Важное ограничение

Библиотека выглядит как историческая база знаний: у большинства страниц нет надежной даты актуализации. Числа, награды, требования, баланс, доступность событий и элементы интерфейса нельзя считать актуальными без проверки по текущему клиенту игры. Для CV-автоматизации библиотеку следует использовать как словарь сущностей и гипотез, а реальные экраны, телеметрию и безопасные dry-run наблюдения — как источник истины.

Сайт отдает HTML в `windows-1251`; некоторые средства чтения ошибаются при декодировании. Для ручной выгрузки подходит:

```sh
curl -L 'https://3kingdoms.ru/info/library/' | iconv -f WINDOWS-1251 -t UTF-8
```

## Как устроены ссылки

- Категория: `https://3kingdoms.ru/info/library/index.php?obj=cat&id=ID`
- Статья внутри категории: тот же URL с `&page=N`
- Не каждая категория имеет несколько страниц: некоторые сразу показывают единственный материал.

Примеры:

## Практическая выжимка

Учебник новичка описывает базовый цикл старого интерфейса: перемещение между локациями, режим охоты, выбор и атаку цели, бой с ударами/заклинаниями, итоговую статистику, добычу и экипировку. В статистике боя мешочек означает награду, значок травмы — полученную травму, череп — возможность снять скальп. Если игрок три раза подряд не отвечает на удары, персонаж автоматически бьет кулаком. Эти сведения полезны как кандидаты на распознаваемые состояния, но визуальные шаблоны и поведение необходимо сверять с текущей версией клиента.

Для задач этого репозитория приоритетны разделы:

1. Учебник и FAQ — терминология интерфейса, бой, квесты, предметы и поддержка.
2. Пути развития — классы/архетипы персонажей и смена пути.
3. Профессии и навыки — сбор ресурсов, ремесло и связанные знания.
4. Репутации, слава и честь — долгосрочный прогресс и награды.
5. Инстансы, события и кланы — отдельные режимы, локации и сценарии.
6. Мир — имена народов, NPC и локаций для словарей OCR и каталогов сущностей.

## Правила использования в проекте

- Не переносить механику из библиотеки в код без подтверждения текущим наблюдением или тестовым fixture.
- При заимствовании названия сохранять русское отображаемое имя и добавлять стабильный внутренний идентификатор проекта.
- Ссылку на конкретную статью и дату проверки фиксировать рядом с извлеченным фактом.
- Визуальные примеры с сайта использовать только как ориентир: текущие размеры, цвета и композиция UI могут отличаться.
- Любые будущие сценарии остаются в рамках политики репозитория: dry-run по умолчанию, действия через safety guard/action sink, без stealth, обходов CAPTCHA и антидетекта.
